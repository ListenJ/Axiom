# 全站审核报告（2026-08-08）

> 范围：①前端部件↔后端执行链效率 ②架构冗余与压力测试 ③知识库等核心部件与前端动画/动态背景可用性。
> 工具：find-skills（检索）、Anthropic code-review / performance / architecture、impeccable（audit/optimize）、bun test:gate、Playwright 探针。

## 一、前端部件 ↔ 后端执行链审核

### 1.1 结论
整体链路健康：核心路径（聊天流式、搜索、Git、终端、知识库）均为单请求/受控轮询，无 N+1、无前端内存泄漏（见 1.4）。发现并修复 2 个真实问题。

### 1.2 已修复
- **右栏隐藏时摘要空转轮询**（效率 P1）：`SummaryPanel` 每 30s 拉取 git.status + git.diff + stats + tokenDetails + agents.status + fileIndex 共 6 个接口；右栏默认收起但组件常驻挂载，导致**隐藏时仍空转**。修复：`paused={!open}`——隐藏时暂停轮询，打开时立即刷新一次（`frontend/src/components/rightbar/panels.tsx`、`RightToolbar.tsx`）。
- **`/vault/para` API 契约悬空**（正确性 P1）：前端 `endpoints.vault.para()` 请求 `/vault/para`，但后端只注册 `/vault/para/:category`，命中 SPA fallback 返回 index.html。修复：后端注册 `GET /vault/para`，返回 PARA 分类分布（vaultStatsCache），实测 200 `{"distribution":{...}}`（`src/routes/vault.ts`、`src/routes/index.ts`）。

### 1.3 审核通过项
- **聊天流式** `/chat/stream`：SSE 增量解析 + 手动 abort 联动，内存/连接安全。
- **搜索**：250ms 防抖 + `/search`、`/search/code` 并行，结果数组化渲染。
- **Git 面板**：status/diff 单次拉取，无高频轮询。
- **终端**：xterm + 独立 session，输入按字符转发（语义正确）。
- **侧栏**：git 60s / sessions 30s 轮询在桌面常驻场景合理；移动端隐藏时仍挂载（低收益，暂不处理）。
- **API 客户端**：GET 缓存（默认 60s）+ 401 闭环 + 超时中断，无 unbounded cache（Map 有容量策略）。

### 1.4 静态资源与运行时
- 前端构建后 `public/` 自托管，无外部 CDN 依赖（Google Fonts @import 已移除）。
- `data-motion` 门禁：动效 off/reduced 时停掉丝绸动画并释放 will-change，CPU≈0、堆≈5MB（此前已实测）。

### 2.2 架构冗余点（评估结论）
- **路由层三层回退**：httpRouter（Trie）→ 传统 `dispatch` → SPA fallback。存在少量重叠，但 Trie 覆盖 153 条显式路由、dispatch 兜底旧路由，属于**有意的向后兼容**，非冗余拷贝；建议后续将 dispatch 中仍被使用的路由逐步迁入 Trie 后移除。
- **静态/SPA 处理**：`serveStaticFile` + `SPA_ROUTES` 白名单 + 回退各司其职；此前 `/` 空 body 问题已修复（`/` 入白名单）。
- **状态管理**：Zustand 单一 store + 局部组件状态，无 Redux 式冗余。
- **结论**：无严重冗余；可优化项为路由收敛与移动端侧栏轮询暂停（低优先）。
