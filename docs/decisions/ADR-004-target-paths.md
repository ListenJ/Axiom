# ADR-004：体验优化目标路径清单与 −20% 步数口径

- 日期：2026-09-11 ｜ 状态：**已采纳** ｜ 决策人：项目经理（用户）
- 背景：T4.2 交互流程简化需锁定目标路径，验收"路径步数 −20%"。仓库无使用频次埋点。

## 决定
**按产品常识锁定三条高频路径**（不等埋点）：
1. **Chat**（对话主路径：发消息 → 看回复 → 追问/切换模型）；
2. **Sessions**（会话管理：找会话 → 恢复 → 删除/重命名）；
3. **Search**（检索：输入 → 过滤 → 定位结果 → 打开）。

口径：以 Playwright 脚本记录的**用户可感知交互步数**（点击/输入/等待跳转各计 1 步）为分子，每条路径减步前后各出一份脚本作为证据（计划 §3 交互简化条款）。

## 理由
- 三条是产品主使用面，价值最高；无埋点下"先补两周埋点"会延迟 T4 开工且收益不确定；
- 步数口径显式定义，避免"提升"不可比（与 ADR-005 同精神）。

## 备选与否决理由
- 先补最小埋点再定：延迟开工、埋点本身需开发，否决（可后续补做校准）。
- 项目经理另行指定：已提供，用户选择按常识清单，采纳。

## 后果与回退条件
- 后果：若真实使用频次与常识不符，可能优化了次优路径。
- 回退：T4.1 若补出埋点数据且显著偏离常识清单，据实调整路径清单并追加本 ADR 记录。
