```
├─────────────────────────────────────────┤
│  2. 关键词匹配层                        │
│     ├── 标题关键词            (×3)      │

│     ├── 内容关键词            (×1)      │
│     └── 路径关键词            (×0.5)    │

│  3. 关系推导层                          │
│     ├── wiki-link 出链        (+10)     │

└─────────────────────────────────────────┘

```

### 记忆存储层

| 存储 | 用途 | 格式 | 共享方式 |
|------|------|------|---------|
| Obsidian Vault | **唯一真理来源** | Markdown + YAML frontmatter | 文件系统（所有 Agent 共享） |
| SQLite FTS5 | 性能索引（可重建） | 结构化数据 | 本地数据库 |
| 知识图谱 | 实体关系 | SQLite | 本地数据库 |

### 代码即记忆

项目源代码通过 `code_index` 自动索引到 Vault：
- 每个 `.ts/.js` 文件 → `03-Resources/code-index/` 下的笔记
- 包含：导出清单、依赖关系、完整代码
- 依赖映射为 `[[module-name]]` wiki-link
- 所有 Agent 可通过 `memory_search` 检索代码
